# fixture-service

Not a real service. It is the smallest repo layout that satisfies the contract of
`.github/workflows/python-service.yml`, and this repo's CI runs the shared workflow against
it (build and scan only, nothing is pushed). It is a copy of the golden-path skeleton from
`surya-idp/idp-portal` (`templates/python-service/skeleton`), rendered with the name
`fixture-service`.
